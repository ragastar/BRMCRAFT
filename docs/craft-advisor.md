# Craft Advisor

Оверлей-советчик по крафту для Path of Exile 2 поверх форка Exiled Exchange 2.
Отвечает не «сколько стоит», а **что докрутить, каким методом и с какой
вероятностью**, чтобы предмет стоил кратно дороже.

## Как пользоваться

1. Запусти PoE2 и оверлей (см. ниже «Запуск»).
2. Наведись на рарный/магический предмет, нажми **Ctrl + E**.
3. Панель покажет базу, iLvl, занятые/свободные слоты префиксов и суффиксов
   и реальные значения свойств предмета (включая имплициты).
4. «🔎 Собрать шаблон (trade2)» — ищет сравнимые предметы, строит шаблон базы
   (частота модов + лучший тир) и выдаёт рекомендации: что оставить, какой мод
   поднять по тиру, какой добавить и есть ли под него слот.
5. «🛠 Подробнее от Claude (опционально)» — Claude объясняет метод крафта и
   приблизительную вероятность поверх этих рекомендаций.

**Стратегия работает через твою подписку Claude Code** (локальный `claude` CLI),
API-ключ не нужен. Требуется установленный и залогиненный Claude Code на этом
компьютере.

Хоткей по умолчанию **Ctrl + E** (поле `hotkey` в конфиге виджета).

## Запуск (dev)

```sh
cd renderer && npm run dev      # Vite на :5173
cd main && npm run dev          # Electron-оверлей (второй шелл)
```

На Windows — `start-craft-advisor.bat` в корне репозитория.

## Архитектура слоёв (PRD)

| Слой | Файл | Статус |
|---|---|---|
| 0 — анализ слотов (база, iLvl, преф/суфф) | `renderer/src/web/craft-advisor/layer0.ts` | ✅ |
| свойства предмета (значения, имплициты) | `item-mods.ts` | ✅ |
| 2 — сравнимые предметы из trade2 | `trade-reference.ts` | ✅ |
| 3 — шаблон базы + рекомендации keep/improve/add | `base-template.ts` | ✅ |
| 4 — feasibility (слот под мод, метод) | `recommend(freeSlots)` + промпт Слоя 5 | частично |
| 5 — метод крафта (текст) | `strategy-prompt.ts`, `strategy-client.ts`, `main/src/craft-advisor/claude-runner.ts` | ✅ Claude через подписку (локальный CLI) |
| хранилище истории цен | `signature.ts`, `price-history.ts` | ✅ модуль готов, к панели не подключён |

### Важное ограничение
Цена листингов в poe2-трейде не используется: рынок бимодален (transmute-джанк
и mirror-витрины), среднего нет, хорошие предметы часто слиты по номиналу.
Поэтому ядро рекомендаций — частота модов и тиры по выборке сравнимых предметов.
Текущую цену смотри в штатном прайс-чеке EE2 (Ctrl + D).

Таблиц весов модов в данных EE2 нет, поэтому вероятность в ответе Claude —
приблизительная оценка, а не расчёт.

## Конфиг виджета

- `hotkey` — шорткат вызова (по умолчанию `Ctrl + E`)
- `openRouterKey` — легаси, не используется (стратегия идёт через подписку)
- `strategyModel` — модель для `claude` CLI (по умолчанию `sonnet`; `opus`/`haiku`/полный id)

Стратегия вызывается через **локальный `claude` CLI на подписке пользователя**
(`main/src/craft-advisor/claude-runner.ts` → роут `POST /claude` в
`main/src/server.ts`). Вызов изолирован: `--system-prompt` заменяет агентный
промпт, cwd = временная папка (без проектного CLAUDE.md), модель санируется.
